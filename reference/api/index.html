Service contract¶

Adopters subclass StacApiService, defined in src/stac_api_protocol/stac_service.py. The HTTP adapter invokes its synchronous methods with parsed filter values. All seven operations belong to the same registered item_service provider.

The constructor requires id, title, and description. Five catalogue operations are abstract. get_landing_page(request) and get_conformance_declaration() are final concrete methods and must not be overridden. The landing page derives its links from the request URL without query parameters. Both responses advertise the four bundled STAC API classes: Core, Item Search, Collections, and OGC API Features.

Operations and routes¶

HTTP route Service method Return type
GET / get_landing_page(request) LandingPage
GET /collections get_collections() Collections
GET /collections/{collectionId} describe_collection(collection_id) pystac.Collection or None
GET /collections/{collectionId}/items get_features(collection_id, limit, bbox, datetime) pystac.ItemCollection or None
GET /collections/{collectionId}/items/{featureId} get_feature(collection_id, feature_id) pystac.Item or None
GET /conformance get_conformance_declaration() ConformanceClasses
GET /search, POST /search get_item_search(bbox, intersects, datetime, limit, ids, collections) pystac.ItemCollection or None

LandingPage, Collections, and ConformanceClasses come from stac_api_protocol.models. Use these existing types rather than creating parallel representations of the HTTP contract.

Filter and result semantics¶

  • bbox is a list of numbers or None; ids and collections are lists of strings or None.
  • datetime is a string or None. The adapter validates timezone-qualified RFC 3339 instants and intervals before delegation. Open interval bounds use ..; both bounds cannot be open, and closed bounds must be ordered.
  • intersects reaches the service as a GeoJSON geometry or geometry collection, or None. In the current implementation, both the GET parameter and the POST SearchBody.intersects field accept a JSON-encoded string. The adapter parses that string before invoking the service.
  • The default limit is 10; HTTP validation constrains supplied numeric limits to 1–10000. The service signature also permits None.
  • Applying filters, choosing items, and constructing result links are the adopter's responsibility. Passing validation does not execute a search.
  • Return ItemCollection([]) for a successful search with no matches. Returning None from an item-list or search operation causes an HTTP 404 response.
  • Return None for a missing collection or individual item. The adapter maps it to HTTP 404.
  • The base class sets LandingPage.conforms_to from its conformance declaration. Its serializer adds conformsTo to the catalogue JSON. ConformanceClasses exposes conforms_to in Python and the conformsTo alias in JSON.
  • Collections wraps PySTAC collections and links and serializes them to JSON.

The landing-page contract requires a LandingPage, although the route also maps an absent result to HTTP 404. Collection-list and conformance methods must return their declared models.

Errors¶

Malformed datetime filters produce HTTP 400. Invalid geometry strings and request validation failures produce HTTP 422. Service exceptions caught by the route handlers become HTTP 500; their current descriptions include the exception text. Avoid putting sensitive data in exceptions that cross this boundary. Unhandled application exceptions are logged and receive a generic HTTP 500 response.

HTTP error bodies use the package's STAC exception model with code and description fields. Service implementations should express normal missing resources through the optional return values above; they do not need to construct FastAPI responses or raise FastAPI exceptions.

class StacApiService(ABC):
    """Provide shared metadata and require adopter-defined catalogue operations.

    Attributes:
        id: Stable catalogue identifier.
        title: Human-readable catalogue title.
        description: Description of the catalogue's contents.
    """

    def __init__(self, id: str, title: str, description: str) -> None:
        """Configure the identity used in the catalogue landing page."""
        self.id = id
        self.title = title
        self.description = description

    @final
    def get_landing_page(self) -> LandingPage:
        """Build metadata and links for the requested catalogue root.

        Args:
            request: Landing-page request whose URL supplies the public catalogue
                root, including any deployment prefix. Query strings are excluded.
        """
        landing_page = LandingPage(
            id=self.id,
            title=self.title,
            description=self.description,
        )

        landing_page.add_link(Link("self", "/"))
        landing_page.add_link(Link("data", "/collections"))
        landing_page.add_link(Link("conformance", "/conformance"))
        landing_page.add_link(Link("search", "/search"))

        landing_page.conforms_to = self.get_conformance_declaration().conforms_to
        return landing_page

    @abstractmethod
    def get_collections(self) -> Collections:
        """Return the catalogue's collection listing and navigation links."""

    @abstractmethod
    def describe_collection(self, collection_id: str) -> Collection | None:
        """Return collection metadata, or None if the collection does not exist."""

    @abstractmethod
    def get_features(
        self, collection_id: str, limit: int | None, bbox: list[float] | None, datetime: str | None
    ) -> ItemCollection | None:
        """Return matching items, an empty result, or None for an unavailable resource."""

    @abstractmethod
    def get_feature(self, collection_id: str, feature_id: str) -> Item | None:
        """Return an item, or None if it does not exist in the collection."""

    @final
    def get_conformance_declaration(self) -> ConformanceClasses:
        """Return a fresh declaration of the four supported STAC API classes.

        Adopter implementations must fulfill these advertised capabilities.
        """
        return ConformanceClasses(
            conforms_to=[
                "https://api.stacspec.org/v1.0.0/core",
                "https://api.stacspec.org/v1.0.0/item-search",
                "https://api.stacspec.org/v1.0.0/collections",
                "https://api.stacspec.org/v1.0.0/ogcapi-features",
            ]
        )

    @abstractmethod
    def get_item_search(
        self,
        bbox: list[float] | None,
        intersects: GeometryGeoJSON | GeometryCollection | None,
        datetime: str | None,
        limit: int | None,
        ids: list[str] | None,
        collections: list[str] | None,
    ) -> ItemCollection | None:
        """Return matching items, an empty result, or None for an unavailable resource."""

def load_dependency(name: str) -> Callable[..., object]:
    """Load the unique callable provider registered under the given name.

    Raises:
        RuntimeError: If no provider, multiple providers, or a non-callable
            provider is registered.
    """
    matches = entry_points(
        group="stacapi.service",
        name=name,
    )

    if not matches:
        raise RuntimeError(f"Missing required dependency: {name}")

    if len(matches) > 1:
        raise RuntimeError(f"Multiple implementations found for: {name}")

    provider: object = next(iter(matches)).load()
    if not callable(provider):
        raise RuntimeError(f"Dependency is not callable: {name}")
    return provider
